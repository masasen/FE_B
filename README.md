# 科目B トレース道場

基本情報技術者試験（FE）科目B の擬似言語トレース練習アプリ。
方眼のメモ欄に自分でトレースを書き、答え合わせで模範のトレース表を
1ステップずつ再生して突き合わせる、という使い方を想定しています。

ビルド不要・外部ライブラリなし。GitHub Pages にそのまま置けます。

## ファイル構成

| ファイル | 中身 | 触る頻度 |
|---|---|---|
| `questions.js` | 問題データだけ | **ここを編集する** |
| `index.html` | 画面の骨組み | ほぼ触らない |
| `style.css` | 見た目 | たまに |
| `app.js` | 採点・ステップ再生の処理 | ほぼ触らない |

## 問題を追加する

`questions.js` の末尾、`];` の直前にカンマ区切りで1問分を貼り付けます。
ひな形と書き方の注意はファイル冒頭のコメントにあります。

iPhone からの編集手順：

1. GitHub アプリでリポジトリを開く
2. `Browse code` → `questions.js`
3. 右上のメニューから `Edit File`
4. 末尾に追記してコミット（1〜2分で Pages に反映）

まとまった修正をするときは、Safari で URL の `github.com` を
`github.dev` に打ち替えるとブラウザ版 VS Code が開きます。

## 動作確認

`index.html` をブラウザで直接開くだけでも動きます（サーバ不要）。
問題を追加して画面が真っ白になった場合は、`questions.js` の
カンマ・引用符の閉じ忘れがほぼ原因です。

## データ保存

メモと正誤は localStorage に保存されます。ブラウザ単位なので、
PC とスマホの間では共有されません。
